# The 48 Engineering Parameters (Matrix 2003)

This skill uses the **modern 48-parameter Contradiction Matrix** (often called "Matrix 2003", developed by Darrell Mann, Ellen Domb, Simon Dewulf, and Boris Zlotin as an expansion of Altshuller's original 39-parameter matrix). It's more granular than the classic matrix — several classic parameters were split apart (e.g. "Loss of substance/time/information/energy" became four separate parameters), and new parameters were added to cover reliability, usability, safety, and system-level concerns that come up constantly in modern product and process design.

When mapping a user's Then/But clause, pick the parameter that best captures the *underlying mechanism* of the effect, not the surface adjective.

| # | Parameter | What it covers |
|---|---|---|
| 1 | Weight of moving object | Mass of an object that moves or can move |
| 2 | Weight of stationary object | Mass of an object fixed in place |
| 3 | Length of moving object | A linear dimension of a moving object |
| 4 | Length of stationary object | A linear dimension of a stationary object |
| 5 | Area of moving object | Surface/area occupied by a moving object |
| 6 | Area of stationary object | Surface/area occupied by a stationary object |
| 7 | Volume of moving object | Space occupied by a moving object |
| 8 | Volume of stationary object | Space occupied by a stationary object |
| 9 | Shape | Outline/contours/form of a system |
| 10 | Amount of substance | Quantity of material/parts used or present |
| 11 | Amount of information | Quantity of data, signal, or knowledge the system holds or conveys |
| 12 | Duration of action of moving object | Service life / how long a moving object functions |
| 13 | Duration of action of stationary object | Service life / how long a stationary object functions |
| 14 | Speed | Velocity of an object or process; rate of change |
| 15 | Force/Torque | Force or rotational force intended to change an object's condition |
| 16 | Energy used by moving object | Energy consumed to perform work while moving |
| 17 | Energy used by stationary object | Energy consumed to perform work while stationary |
| 18 | Power | Rate of energy use (energy per unit time) |
| 19 | Stress/Pressure | Force per unit area |
| 20 | Strength | Resistance to breaking, deforming, or failing under force |
| 21 | Stability | Wholeness/robustness of a system's composition and behavior over time |
| 22 | Temperature | Thermal state of an object or system |
| 23 | Illumination intensity | Light output, luminous flux, illumination level |
| 24 | Function efficiency | How effectively the system converts input into intended output |
| 25 | Loss of substance | Material wasted, leaked, or degraded |
| 26 | Loss of time | Time wasted; efficiency in the temporal sense |
| 27 | Loss of energy | Energy wasted without contributing useful work |
| 28 | Loss of information | Data, signal, or knowledge lost or degraded |
| 29 | Noise | Unwanted acoustic (or by extension, signal) disturbance produced |
| 30 | Harmful emissions | Unwanted substances or radiation released into the environment |
| 31 | Other harmful effects generated by object | Negative effects (not emissions/noise) the system itself produces |
| 32 | Adaptability/versatility | Ability to respond positively to external changes, or serve multiple functions |
| 33 | Compatibility/connectability | Ease of interfacing/integrating with other systems or components |
| 34 | Usability/trainability | Ease of learning to use the system correctly |
| 35 | Reliability/robustness | Ability to perform intended function consistently over time/conditions |
| 36 | Repairability | Ease of fixing faults; time/quality/cost of repair |
| 37 | Security | Resistance to unauthorized access, tampering, or intentional harm |
| 38 | Safety/vulnerability | Exposure to accidental harm; how safe the system is to be around |
| 39 | Appearance & aesthetics | Visual/sensory appeal of the system |
| 40 | Other harmful effect on system | Negative effects something external inflicts on the system |
| 41 | Manufacturability | Ease/cost of producing the object |
| 42 | Manufacturing precision/uniformity | How closely a manufactured part matches its specification, batch to batch |
| 43 | Automation | Extent a system performs its function without human intervention |
| 44 | Productivity | Output (functions or objects) per unit time |
| 45 | Complexity of system | Number and diversity of elements and their interrelations |
| 46 | Complexity of control | Difficulty of measuring/monitoring/controlling a system |
| 47 | Ability to detect/measure | How easily a property or state of the system can be observed |
| 48 | Measurement precision | Closeness of a measured value to the true value |

## Mapping tips

- Cost isn't a parameter here either — trace it to its mechanism: usually 10 (Amount of substance), 41 (Manufacturability), 26 (Loss of time), or 44 (Productivity).
- "Breaks / fails" → 35 (Reliability/robustness) for consistency of function, 20 (Strength) for resisting a specific force, 12/13 (Duration of action) for lifespan.
- "Confusing / hard to learn" → 34 (Usability/trainability). "Awkward to operate day-to-day" once learned → still often 34, or 33 if it's about fitting into an existing workflow/toolchain.
- "Hackable / exploitable" → 37 (Security). "Dangerous to be around" (accidental, not adversarial) → 38 (Safety/vulnerability).
- Software/process contradictions map fine here: "server load" ≈ 18 (Power) or 16/17 (Energy used); "response time" ≈ 14 (Speed) or 26 (Loss of time); "codebase complexity" ≈ 45 (Complexity of system); "hard to debug/observe" ≈ 46 (Complexity of control) or 47 (Ability to detect/measure).
