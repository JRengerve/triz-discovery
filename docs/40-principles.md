# The 40 TRIZ Inventive Principles

Use these definitions when writing Step 4 of the skill — translate the mechanism below into something concrete for the user's actual problem, don't just restate the definition.

1. **Segmentation** — Divide an object/system into independent parts; make it easy to assemble/disassemble; increase the degree of fragmentation.
2. **Taking out (extraction)** — Separate an interfering part or property from an object, or extract the one necessary part/property.
3. **Local quality** — Change a uniform structure/property into a non-uniform one; make each part suited to its own local function.
4. **Asymmetry** — Replace a symmetrical form with an asymmetrical one; if already asymmetrical, increase the asymmetry.
5. **Merging (consolidation)** — Bring closer together, or merge, identical or related objects/operations so they run in parallel or as one.
6. **Universality** — Make one part or object perform multiple functions, eliminating the need for other parts.
7. **Nesting** — Place one object inside another; that inside a third; and so on ("Russian doll").
8. **Anti-weight (counterweight)** — Compensate for an object's weight by merging it with objects that provide lift, or by interaction with the environment (aerodynamic, hydrodynamic, buoyant forces).
9. **Preliminary anti-action** — If an action will have both harmful and useful effects, perform an anti-action in advance to control the harmful effect.
10. **Preliminary action** — Perform the required change of an object, in full or in part, before it is needed.
11. **Beforehand cushioning (compensation)** — Prepare emergency backup/compensation means in advance to offset the relatively low reliability of an object.
12. **Equipotentiality** — Change operating conditions so an object doesn't need to be raised or lowered (eliminate potential-energy transitions).
13. **The other way round (inversion)** — Invert the action; make movable parts fixed and fixed parts movable; turn the object/process upside down.
14. **Spheroidality / curvature** — Replace flat surfaces/straight lines/cubic forms with curved, spherical, or rounded ones; use rollers, balls, spirals.
15. **Dynamics** — Allow (or design in) characteristics, an object, or a process to change to be optimal at each stage of operation; divide into parts capable of movement relative to each other.
16. **Partial or excessive action** — If 100% of an effect is hard to achieve directly, use slightly less or slightly more to simplify the problem.
17. **Another dimension** — Move an object/process into two or three dimensions instead of one; use a multi-story arrangement; tilt or reorient it.
18. **Mechanical vibration** — Cause an object to oscillate or vibrate; increase frequency (even to ultrasonic); use resonance.
19. **Periodic action** — Replace a continuous action with a periodic or pulsed one; if already periodic, change the frequency or pattern.
20. **Continuity of useful action** — Carry out work continuously, with all parts of a system operating at full load, eliminating idle/intermediate motion.
21. **Skipping (rushing through)** — Conduct a process, or particularly its harmful/hazardous stages, at high speed.
22. **Blessing in disguise (convert harm to benefit)** — Use harmful factors/effects to achieve a positive outcome, or eliminate a harmful factor by combining it with another harmful factor.
23. **Feedback** — Introduce feedback to monitor and improve a process; if feedback already exists, change its magnitude or timing.
24. **Intermediary** — Use an intermediary object/process to carry out an action, or temporarily merge one object with another that's easily removed.
25. **Self-service** — Make an object serve itself by performing auxiliary, repair, or maintenance functions; make use of waste resources.
26. **Copying** — Use a simple, cheap copy (optical, digital, simulated) instead of an object that is complex, expensive, fragile, or inconvenient to use directly.
27. **Cheap short-living objects** — Replace an expensive object with multiple cheap ones, trading off qualities like longevity for cost.
28. **Mechanics substitution** — Replace a mechanical means with a sensory one (optical, acoustic, thermal, olfactory); use fields to interact with the object instead.
29. **Pneumatics and hydraulics** — Replace solid parts of an object with gas or liquid; use air/water cushions, inflatable, or hydrostatic elements.
30. **Flexible shells and thin films** — Replace conventional/rigid structures with flexible shells or thin films; isolate an object using thin flexible membranes.
31. **Porous materials** — Make an object porous or add porous elements; if already porous, fill the pores in advance with something useful.
32. **Color / optical property changes** — Change the color or transparency of an object or its surroundings to change its perceived or actual properties.
33. **Homogeneity** — Make objects that interact with a given object out of the same (or property-matched) material.
34. **Discarding and recovering** — Make parts that have finished their function disappear (dissolve, degrade, self-eject) or be restored during operation.
35. **Parameter changes** — Change an object's physical/chemical state, concentration, consistency, flexibility, or temperature.
36. **Phase transitions** — Use phenomena occurring during a phase transition (volume change, heat absorption/release, etc.).
37. **Thermal expansion** — Use thermal expansion or contraction of a material; combine materials with different expansion coefficients.
38. **Strong oxidants (accelerated oxidation)** — Replace normal air/environment with an enriched, ionized, or accelerated-reaction one to speed a process.
39. **Inert atmosphere** — Replace a normal environment with an inert one; carry out a process in vacuum.
40. **Composite materials** — Replace a homogeneous material with a composite one, combining materials to get properties neither has alone.
